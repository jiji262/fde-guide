## FDE 不是终点，是一张跳板

先给结论:FDE 这个岗,最值钱的地方不是它本身的薪水,是它给你攒下的那身"可迁移的肌肉"。所以你别把它当终点站,当成一张跳板来打。

我知道有人劝退你,说这活儿累。累是真的,后面我们会讲代价。但你先记住一个数:Palantir 的校友——大部分是 FDE 出身——已经创办了 111 家以上的公司,累计融资 116 亿美元。这不是巧合。一个能被"嵌进客户现场、端到端 own 一个高风险项目"反复锤炼的人,出来干什么都不怵。

就像你在部队里当过前线指挥官,退役之后,你比谁都清楚一支队伍怎么从零拉起来、怎么在信息不全的时候做决定。FDE 攒的就是这种东西。

那具体能跳去哪?Niles Lawrence 给了一张最干净的地图。他自己的路径是 Palantir FDE → Enterprise Lead → Sierra 的 Agent PM,一路走过来,他总结出 FDE 的四个出口:

| 出口 | 你带走的核心能力 | 适合什么样的你 |
|---|---|---|
| 售前 / 解决方案 | 客户面能力、把技术翻译成业务价值 | 喜欢和人打交道、擅长讲故事 |
| 基础设施 / 平台 | 把一次性交付抽象成可复用平台 | 想沉淀、不想每次从零 |
| 自己开一家交付公司 | 端到端 own、"startup CTO"那套 | 有创业心、扛得住不确定 |
| 产品(PM / 工程) | 一线洞察反哺产品的直觉 | 想离用户近、又想做长期的东西 |

[[FIG:niles-four-exits | Niles 的 FDE 四出口：售前、基础设施、自开交付公司、产品，四个方向从同一个圆心散出]]

除了这四个,还有第五条更野的路。Langer 走的是 FDE → 天使投资人。这条逻辑你想想就通:FDE 天天泡在几十家企业的真实生产环境里,谁的痛点真、谁的方案能落地、哪个赛道在起量,你比任何一个只看 pitch deck 的投资人都清楚。你手里攥的是别人花钱都买不到的一线信息差。

传统程序员的职业路径,大多是"更资深的程序员 → 架构师 → 技术管理",一条道走到黑,越走越窄。FDE 反过来,它像一个"能力中转站":进来的时候你是个工程师,出去的时候你可以是 PM、是创始人、是投资人。这就是我说它是跳板的意思。

## 国内往上走，和一个正在长出来的邻居岗

结论先给:在国内,FDE 的晋升序列已经跑出来了,是 FDE → FDE Leader → FDE 负责人;同时旁边还长出一个和你血缘很近的岗——AI Evals Engineer,值得你早点留意。

先说国内的往上走。别以为这是画饼,已经有实证。智谱在招"FDE 负责人",月薪 6–8 万。深圳有 AI 厂商开出 FDE Leader 年薪 300 万(这是极值,别拿它当均值)。猎聘上年薪 50–100 万的 FDE 岗接近 300 个,百万以上的有 40 多个。这条管理序列是真的通的。

但我得对你诚实,免得你被数字冲昏头。国内初级 FDE 的实证薪资,上海是月薪 2–3 万,高职级年包 40 万+。"年薪百万"是塔尖上极少数人的故事,不是你入门就能摸到的。所以看清楚:上升空间是真的,但底部没那么甜。

[[FIG:domestic-ladder | 国内 FDE 三级晋升阶梯：FDE → FDE Leader → FDE 负责人，右侧标注实证薪资带]]

还有个方向别投错。国内招 FDE 的,集中在云厂商(腾讯云、阿里云、火山引擎)和应用服务商。像 DeepSeek、月之暗面、MiniMax 这些做模型研究的公司,基本不设 FDE——它们的岗位几乎都围着 LLM 本身转。你要是抱着简历往模型公司投 FDE,大概率石沉大海。这就像你想当船长,得去航运公司,别去造船厂。

再说那个邻居岗:AI Evals Engineer。这岗现在已经从 FDE 的技能里独立出来,单独成岗了,入门年薪 13 万–17.3 万美元。为什么它和你血缘近?因为 evals 本来就是 FDE 全线最重的一块硬技能——你在客户现场把 demo 和"能上线"分开,靠的就是它。

我的建议是:你把 evals 这块练到别人来问你的程度。这样一来,就算哪天你不想做 FDE 的差旅和客户面了,横向平移去做 AI Evals Engineer,几乎是无缝的。你等于同时握着两张牌。

传统的做法是,你在一个岗位上死磕到底,退路只有"跳槽做同样的岗"。FDE 这套技能给你的,是"一专多能"的横向流动性——同一身本事,能往好几个方向兑现。

## 别掉队：把学习变成一条订阅制的水管

结论先给:FDE 这行的知识半衰期短得吓人,你不能"学一波吃三年"。你得把持续学习做成一条一直流着的水管,而不是隔三差五灌一大桶。

怎么灌不重要,重要的是别停。我给你两条最省事的管子。

第一条,信息源。订 FDE Hub(fdehub.org),每周四更新一期从业者访谈,访谈对象是 Palantir、Sierra、Ramp、Baseten 这些公司的真人。这是目前最好的持续素材源之一——它办的人 Milos Mandic 自己就是一线 FDE,同时跑 10–15 个客户。你每周花二十分钟听一期,就等于蹭了一次一线的信息更新。

就像你健身不是靠某一天练到吐,是靠每周三练、常年不断。学习也一样,订阅制的每周一点点,比你憋一个月啃一本大书管用得多。

[[FIG:learning-pipeline | 一条持续流动的学习水管：左端是 FDE Hub 每周订阅，中段是免费证书串，右端汇入个人作品集]]

第二条,凭证策略。这里我要帮你省钱、也帮你避坑。2026 年中,值得你花时间考的凭证,就这么几样,别的先别碰:

- **Anthropic Academy 免费证书串**:开发者路径一条龙——Claude 101 → Building with the Claude API → MCP 入门/进阶 → Agent Skills / Subagents → Claude Code in Action。全免费,每门都发结业证书。你可以集齐一整串挂在简历上。
- **Claude Certified(via Pearson VUE)**:Anthropic 的正式认证,分 Practitioner / Architect / Developer 三个角色,通过 Pearson VUE 考。目前偏向合作伙伴,但含金量在那儿,值得盯着。
- **阿里云大模型 ACP**:约 ¥1000,考纲和 FDE 技能栈六个模块高度重合,是国内简历上拿得出手的证书锚点。

那不该碰的呢?OpenAI 的正式个人认证,截至 2026 年中还在企业试点,没对个人开放,你现在惦记它没用。

[[FIG:cert-strategy-2026 | 2026 年中凭证策略三选：Anthropic Academy 免费串 + Claude Certified + 阿里云 ACP，旁边打叉的是尚未开放的 OpenAI 认证]]

但我得把最重要的一句话放在这:证书是敲门砖,作品集才是硬通货。一个真实部署过、带着 eval 指标的项目,招聘方 60 秒就能验证你行不行。证书只能证明你"学过",作品集能证明你"做成过"。

传统求职是"证书越多越好,堆满一简历";FDE 这行反过来——招聘方扫一眼你有没有 live URL、有没有 eval 前后对比的指标表,那比十张证书都有说服力。所以你的时间账要这么算:考免费证书顺手集串,但真正的重仓,押在一个能公开展示的部署项目上。

## 给你画一张个人三年路径图

结论先给:光知道出口和资源还不够,你得把它落成一张自己的三年图。别嫌它糙,画出来你才知道下一步动哪。

我给你一个可以直接抄的骨架。你把里面的空填成你自己的情况:

```text
第 1 年 · 立足
  目标：活下来 + 交出 2 个真实客户的端到端部署
  重仓：evals + MCP（这两样练到能给别人讲）
  证据：1 个带 live URL + eval 指标的旗舰作品集
  订阅：FDE Hub 每周四，雷打不动
  证书：Anthropic Academy 免费串集齐 + 阿里云 ACP

第 2 年 · 拔高
  目标：从"被分配客户"到"能独立带一个交付"
  选向：盯住 Niles 四出口，选 1 个开始攒对应能力
    - 想做产品 → 每个客户留一页"洞察→产品建议"
    - 想做平台 → 把重复交付抽象成可复用模块
  证据：2–3 篇部署/评测实战长文（公开写作 = 敲门砖）
  国内：对齐 FDE → Leader 序列，主动 own 更难的客户

第 3 年 · 转向
  目标：兑现跳板价值
  出口：售前 / 基础设施 / 自开交付公司 / 产品 / 天使
  或者：横移去 AI Evals Engineer（evals 肌肉直接复用）
  底牌：111 家公司 / 116 亿融资 的校友网络逻辑——
        你攒的是"从零拉起一个系统"的通用能力
```

[[FIG:three-year-map | 个人三年路径图：第 1 年立足、第 2 年拔高、第 3 年转向，每年标注目标、重仓技能和产出证据]]

看懵了也没关系,你不用一次填满。这张图的用法是:每季度拿出来对一次,问自己两个问题——我这季度攒的能力,对得上我选的那个出口吗?我手里的作品集,有没有比上季度多一份能被 60 秒验证的证据?

对得上,就继续;对不上,就调。这比你埋头干、干到第三年才抬头发现方向错了,强太多。

传统职业规划是"先定一个十年目标,然后一条路走到底";FDE 这行变化太快,十年图没意义。你要的是一张"每季度可校准"的活地图——方向大致对,节奏随时调。

## 小结

这一讲我们把 FDE 的长期出路铺开了。往外看,有 Niles 的四出口(售前/基础设施/自开公司/产品)加上 Langer 的天使路径;往上看,国内有 FDE → Leader → 负责人的序列,旁边还有 AI Evals Engineer 这个可无缝平移的邻居岗。持续学习靠两条水管:FDE Hub 每周订阅,加上 2026 年中值得考的凭证组合(Anthropic 免费证书串 + Claude Certified + 阿里云 ACP)。但记住,作品集永远比证书硬。最后,把这一切落成一张每季度可校准的三年图。
